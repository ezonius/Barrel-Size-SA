# Barrel Size (SA Update)

Customize the fluid capacity of barrels — updated for **Factorio 2.1 / Space Age**.

Originally by Schmendrick, updated by ezonius.

## What it does

Barrels are often annoyingly small in vanilla (50 units of fluid, stack of 10). This mod lets you tune barrel behavior with three **startup settings** (require a map restart / new game to change):

| Setting | Default | Description |
|---|---|---|
| Barrel stack size | 10 | How many barrels fit in a single inventory slot |
| Barrel capacity | 50 | How much fluid each barrel holds (fill/empty recipe amount) |
| Barrel fill time | 0.2 s | Crafting time of the fill/empty barrel recipes |

## Compatibility

- Works with Space Age (factorio_version 2.1).
- Optional support for **PressurizedBarrels** and **more-barrels**: if either is installed, its changes are applied first, then this mod re-applies its capacity and fill time to the (mod-added) fill/empty recipes.
